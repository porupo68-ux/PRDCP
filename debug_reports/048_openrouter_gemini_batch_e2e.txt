Failures and root causes
------------------------
1. Batch transport and Retrieval
   - The :batch model cannot be sent to the synchronous chat endpoint.
   - Durable Batch submission/polling was implemented with saved remote identity.
   - Google/OpenRouter Batch web-search ended terminally even though minimal
     text-only and Structured Output Batch jobs completed.
   - Recovery therefore required one explicitly authorized synchronous Retrieval
     identity. Completed Topic Scout and Topic Selector checkpoints were reused.

2. Gemini request-schema INVALID_ARGUMENT
   - Producer and Researcher dynamic source binding remained correct: only compact
     source IDs were placed in enums and retrieved identity was hydrated locally.
   - Deliberation Stakeholder and Conclusion Position schemas were syntactically
     strict but too complex for Gemini's opaque controlled-generation compiler.
   - The canonical Pydantic schemas were not weakened. Only the Gemini wire view
     omits titles, string length/pattern annotations, and array cardinality
     annotations. Types, properties, required keys, closed objects, and ID enums
     remain authoritative, and Pydantic validates the response afterward.
   - A request-schema contract repair may reuse the configured model only when it
     is correlated to the named gemini_wire_schema_v2 revision. It does not create
     a model compatibility fallback binding. Response-contract repair still
     requires a distinct model.

3. Playwright Citation schema union explosion
   - Sixteen paragraph-correlated variants expanded the exact Citation wire schema
     to 24,450 bytes, 90 total anyOf branches, 38 anyOf nodes, and depth 11.
   - Gemini rejected it with HTTP 400 INVALID_ARGUMENT.
   - Correlated variants are now bounded at eight. Longer scripts retain the
     global canonical ID allowlists in the strict schema; the existing
     deterministic Playwright validator enforces paragraph-local
     Claim/Evidence/Source correlation.
   - Provider preflight rejects a single anyOf with more than eight branches.
     It deliberately does not reject the aggregate number of small unions because
     Researcher schemas with larger aggregate counts succeeded in real calls.

4. Playwright Final Gate findings
   - After Citation/Visual recovery, Safe Mode stopped at the Final Gate because
     required QUESTION and LIMITATION sections were absent.
   - One explicit Playwright internal revision reran only its dependency closure.
     The second Final Gate passed. The remaining script character-count mismatch
     is a non-blocking warning and is disclosed in the final package.

Why Mock and Doctor did not detect the failures
-----------------------------------------------
Mock validates PRDCP contracts but does not compile the exact dynamic production
schema with Google's controlled-generation grammar. Doctor and the 22-root audit
exercise static root schemas, while the failing schemas were specialized with real
candidate, source, paragraph, claim, evidence, and source ID sets. Previous
preflight bounded total bytes and enum payloads but not per-node union width. The
new regression suite therefore builds dynamic production-sized schemas and applies
the same provider-bound specialization and compatibility gate used immediately
before HTTP.

  authorizations.

  infer that an ambiguous request is safe to resend.

  drift fails CI.
