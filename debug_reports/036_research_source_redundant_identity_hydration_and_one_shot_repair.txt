2. Root cause

ResearchSource contained three independent representations of the same source identity:

* source_name;
* author_or_organization;
* the source-type-specific identity such as GovernmentMetadata.organization.

The latter is the typed, category-specific canonical field. The first two are redundant
presentation aliases, but the strict Provider schema asked Gemini to generate all three
independently. Even when the facts were compatible, normal wording variation could make
the redundant alias fail exact grounding.

For the observed source, 内閣府知的財産戦略推進事務局 is present in the saved PDF with a
layout whitespace difference already handled by Cycle 035. 内閣官房 is represented by the
immutable saved www.cas.go.jp URL. The combined value was nevertheless searched as one
literal substring, which cannot exist across the URL and document text boundary.

This was not missing Evidence and not a Retrieval failure. It was an output ownership
error: a value derived from already structured identity metadata was still delegated to
the generative Provider.

3. Why Mock and Doctor did not detect it

Mock fixtures produced identical values in source_name, author_or_organization and typed
metadata, so no spelling divergence occurred. Cycle 035 Fault Injection covered Unicode,
PDF layout whitespace, country domains and analytical classifications, but did not inject
a composite organization into a redundant alias.

Doctor verifies runtime configuration and Provider capability. It cannot detect semantic
duplication inside a valid schema. The required protection belongs in strict-schema
specialization, deterministic output hydration and contract Fault Injection.

4. Repair design

For every one of the seven Researcher source categories, the Provider-bound strict schema
now omits source_name and author_or_organization. The model produces one typed primary
identity only:

* EXPERT: expert_name
* ACADEMIC: journal_name
* GOVERNMENT: organization
* NEWS: media_name
* PUBLIC_OPINION: platform
* POLITICIAN: politician_name
* INDUSTRY: organization_name

After the response returns, the shared ResearcherAgent deterministically hydrates both
presentation aliases from that primary identity. Existing Pydantic models, saved JSON,
Research Report materialization, deduplication and downstream contracts remain unchanged.
The compatibility change is therefore confined to the Provider boundary.

Government composite organizations remain permitted only when every component is
individually grounded. A component must occur in normalized saved title/URL/content or be
an exact member of a closed alias list for the immutable official hostname. The mapping
covers the observed cas.go.jp case and audited official domains used by the current saved
Contexts. An unrelated organization such as 総務省 on cas.go.jp remains rejected.

Producer General Opinion uses its separate SupportingSource schema, already reduced to a
retrieved source_id, and is not changed. Deliberation, Conclusion and Playwright do not
emit ResearchSource identity aliases and are unaffected.

The authorization is consumed only after its new reservation is durable and before the

existing Cycle 032 state machine, which executes only the eight untouched tasks,
integration and one Quality Review. Retrieval is never re-run.
