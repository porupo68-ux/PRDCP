1. What happened

Cycle 033 persisted all nine missing Researcher Retrieval Contexts and then invoked the
first Gemini Structured Reasoning task. Gemini selected a source_id that exists in the
saved Context, but returned relevant_excerpt as a reformatted or paraphrased string. The
local output contract correctly rejected a quotation that was not an exact substring of
the immutable source text.

The consumed task identity was:

task_1abf9d163f0f4c20980e4221ca960e1e_runtime_model_repair_1

The correlated ERROR PMP was d9dad747-bc78-4d6b-9fc0-83650caf7a3e. The workflow stopped
before the remaining eight reasoning calls and before Researcher Quality Review.

2. Root cause

Cycle 030 had already established the correct boundary for immutable Retrieval metadata:
the model selects source_id, while title, URL and retrieved_at are restored from the
persisted Context. relevant_excerpt was unintentionally left on the model-generated side
of that boundary.

An excerpt is a quotation, not an analytical judgment. Asking a generative model to copy
it byte-for-byte and then enforcing exact-substring validation created an unstable
contract: a semantically faithful whitespace change or paraphrase was rejected after a
successful paid call. The validator was correct; the producer of the field was wrong.

3. Why Mock and Doctor did not detect it

The Mock Researcher fixture returned an excerpt already copied from its synthetic
Retrieval content, so it never injected the observed paraphrase/formatting difference.
Cycle 030 Fault Injection covered long titles, large dynamic enums and all eight
Retrieval-agent schemas, but did not mutate relevant_excerpt after source_id selection.

Doctor verifies current configuration, RD loading, model capability and Retrieval
availability. It does not and should not predict semantic formatting choices in a future
provider response. The missing protection belonged in the deterministic output adapter
and its Fault Injection tests.

4. Repair design

All seven Researcher specialists share one repaired ResearcherAgent adapter:

* relevant_excerpt is removed from the Provider-bound strict schema together with title,
  URL and retrieved_at;
* the model still selects only an allowed source_id and generates analytical fields;
* after response parsing, the adapter restores a bounded exact slice (maximum 1,000
  characters) from the persisted source content;
* the existing exact-substring validation remains enabled;
* unknown source_id and ungrounded identity metadata remain rejected.

This avoids weakening traceability. It strengthens it by making the stored quote a
deterministic function of the immutable Retrieval checkpoint.

5. Recovery identity and billing safety

The consumed Cycle 032 runtime repair identity is never reopened. A new command was
added:

py main.py --researcher-runtime-output-repair WORKFLOW_ID --provider openrouter --safe-mode

It creates exactly one new identity:

<original_task_id>_runtime_model_output_repair_1

Authorization requires all of the following before a Provider reservation is created:

* the matching runtime-model repair authorization is CONSUMED;
* its Provider reservation matches workflow, task, agent and model;
* the correlated ERROR PMP is NonRetryableAgentError with the exact excerpt-contract
  prefix and a source_id present in the saved Context;
* Retrieval ID and file SHA-256 still match the consumed authorization;
* no consumed runtime-output repair already exists.

The new authorization is consumed only after its distinct Provider reservation is durably
written and before the Provider invocation. Failure or ambiguity therefore blocks any
second output-repair call. A PENDING authorization created before reservation can be
resumed safely; a CONSUMED authorization cannot.

After the repaired result is durably stored, the existing Cycle 032 state machine handles
only the eight untouched tasks, integration and Quality Review. Retrieval is never
re-executed.

6. Same-family impact audit

The schema and hydration change applies uniformly to Expert, Academic, Government, News,
Public Opinion, Politician and Industry Researcher agents. Producer General Opinion uses
a separate SupportingSource adapter and was not changed. Deliberation, Conclusion and
Playwright do not produce ResearchSource excerpts and are unaffected.

The common provider reservation pipeline gained only a suffix-specific authorization
branch. Existing operator retry, contract repair, capability repair, Producer output
repair and runtime-model repair identities retain their previous stores and semantics.
